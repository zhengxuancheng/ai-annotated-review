# Support

For public repository support, use GitHub issues after the repository is published:

```text
https://github.com/zhengxuancheng/ai-annotated-review/issues
```

Use issues for:

- reproducible bugs,
- documentation problems,
- feature proposals,
- adapter proposals,
- verification failures.

Do not include private documents, secrets, raw chat histories, credentials, or personal data in public issues.

For OpenAI app submission, the public privacy/support contact is still an owner-side release gate. Until that contact is finalized, this repository should not claim final public app approval or directory availability.
